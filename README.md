# 字幕剪辑重排工具（SRT Clip Remap）

本地运行的网页工具：粘贴 SRT 字幕，按播放顺序输入剪辑段的**源起止毫秒与倍速**，
自动把每条字幕裁剪、跨切点拆分、按倍速映射到拼接后的新时间轴，并可下载新的 SRT 文件。
结果页还可粘贴**同一源时间轴上的译文 SRT**，沿用本次剪辑段与倍速重排后做双语配对、下载双语 SRT；
也可对输出条目提交**源字幕勘误**，按源字幕归并回写并导出修订后的源 SRT；
并可对当前输出做**字幕时间避让**：按设定的最小间隔与最大平移量整体平移各条字幕，
下载避让版 SRT；还可对当前未排版输出做**阅读时窗审计**：按字素簇计阅读量
（ASCII 簇 1、其他簇 2、空白不计），设置 1～40 单位/秒的整数阅读速度，按最早截止
时间优先在各条字幕的半开显示区间内分配可暂停/继续的单人阅读量（整数千分之一单位、
不逐毫秒取整），逐条给出需求量、已读量、欠量并标出最早失约时刻；还可输入 2～10 个「旧毫秒 新毫秒」同步锚点做**成片同步校准**，
相邻锚点间线性比例映射、首末锚点外沿用最近锚点固定偏移（整数分子/分母保精度，边界最后分别四舍五入），
对照原时间与校准时间并下载校准版 SRT；还可输入第二套剪辑段做**剪辑方案对照**，逐区间比较两方案的覆盖与播放时长；
并可逐行输入源时间轴的「起始毫秒 结束毫秒 说话人ID」做**说话人标注**，
按同段正时长交集判定每条输出字幕的说话人（并列逐条裁决），下载正文前加「[ID] 」的标注版 SRT。

- 后端：Node.js + Express
- 前端：原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- **无需任何外部服务**，数据不出本机

## 一条命令启动（Docker）

```bash
docker compose up --build -d
```

启动后浏览器访问：

```
http://localhost:3000
```

端口固定为 **3000**（容器内 `3000` → 宿主机 `3000`）。停止：

```bash
docker compose down
```

> 如需更换宿主机端口，修改 `docker-compose.yml` 中的 `"3000:3000"`（左侧为宿主机端口）。

## 不用 Docker 直接运行（需 Node.js ≥ 18）

```bash
npm install
npm start
# 访问 http://localhost:3000
```

可用环境变量 `PORT`（默认 3000）、`HOST`（默认 0.0.0.0）调整监听地址。

## 使用方法

1. 左侧粘贴源 **SRT 字幕**（标准格式，支持 CRLF、BOM、点号毫秒分隔符）。
2. 右侧按**播放顺序**每行输入一条剪辑段：

   ```
   源起毫秒 源止毫秒 倍速
   ```

   - 字段间用**空白或逗号**分隔（可混用）；`#` 之后为注释，空行忽略。
   - 倍速仅允许 `0.5`、`1`、`2`。
   - 源段允许**乱序、重叠、重复**；重复出现的源段会各自独立生成字幕。

   示例：

   ```text
   # 源起ms 源止ms 倍速
   0 5000 1        # 正常速度前 5 秒
   10000 13500 2   # 2 倍速
   3000 6000 0.5   # 倒回慢放（乱序源段）
   0 2000 1        # 重复使用的源段
   ```

3. 点击「生成重排字幕」（快捷键 Ctrl/⌘ + Enter），页面展示对应关系与结果，可「下载单语 output.srt」或复制文本。
4. 页面内置「填入示例」按钮，可快速体验跨切点拆分、乱序、慢放与重复段。
5. 在结果页用「字幕自动换行」工具条设置**每行宽度上限（4～40）**即可逐条排版，详见下节。
6. 在结果页「双语字幕配对」工具条粘贴**同一源时间轴上的译文 SRT**并点击「配对译文」，
   详见「双语字幕配对（结果页）」一节。
7. 在结果页「**源字幕勘误**」标签页（或「输出字幕列表」每行的「勘误」按钮）对输出条目的
   未排版正文提交修订，可导出勘误后的源 SRT 并预览重新重排结果，
   详见「源字幕勘误回写（结果页）」一节。
8. 在结果页「**成片口播稿核对**」工具条粘贴按成片播放顺序整理的口播纯文本并点击「核对口播稿」，
   核对在后台线程进行（可随时取消），详见「成片口播稿核对（结果页）」一节。
9. 在结果页「**字幕时间避让**」工具条设置**最小间隔**与**最大平移量**即自动重算排程，
   「时间避让对照」标签页逐条对照原时间/新时间/位移，可下载避让版 SRT，
   详见「字幕时间避让（结果页）」一节。
10. 在结果页「**阅读时窗审计**」工具条设置 **1～40 单位/秒的整数阅读速度**即自动审计，
    「阅读时窗审计」标签页逐条显示需求量、已读量与欠量，并标出最早失约时刻，
    详见「阅读时窗审计（结果页）」一节。
11. 在结果页「**剪辑方案对照**」工具条输入**方案 B 的剪辑段**并点击「对照方案」，
    「方案对照」标签页逐区间比较两套方案的覆盖次数与精确播放时长，
    详见「剪辑方案对照（结果页）」一节。
12. 在结果页「**成片同步校准**」工具条逐行输入 **2～10 个「旧毫秒 新毫秒」同步锚点**
    并点击「应用校准」，「同步校准对照」标签页逐条对照原时间/校准时间，
    可下载校准版 SRT，详见「成片同步校准（结果页）」一节。
13. 在结果页「**说话人标注**」工具条逐行输入源时间轴的「起始毫秒 结束毫秒 说话人ID」
    并点击「应用标注」，「说话人标注」标签页逐条对照各说话人交集时长与归属，
    并列逐条裁决后可下载标注版 SRT，详见「说话人标注（结果页）」一节。

## 字幕自动换行（结果页）

以**当前输出字幕**（重排结果）为输入，对每条字幕单独排版：

- **只调整空白与换行**：去除首尾空白、连续空白折叠为一个空格、在合法断点处插入/移除换行；
  非空白字符（含标点、emoji）的顺序、字幕编号、时间轴以及源字幕对应关系**完全不变**。
- 宽度计量：**ASCII 字素簇计 1，其他字素簇（汉字、全角标点、emoji 及 ZWJ 组合）计 2**
  （以 `Intl.Segmenter` 字素簇切分）。
- **连续 ASCII 字母数字 `[A-Za-z0-9]+` 不可拆分**，作为整体原子参与排版。
- 每条字幕**最多三行**；行首不得是空白或 `，。！？、；：）》」` 中的字符，
  行尾不得是空白或 `（《「` 中的字符。CJK 字间原本没有空白也允许插入换行。
- 断点择优顺序：
  1. 行数最少；
  2. 行数相同时，使**各行剩余宽度（上限 − 行宽）的平方和最小**；
  3. 仍相同时，取**更靠前**的断点。
- **无解时保留原文**，并在「排版逐条对照」页标出原因：
  - `token-too-wide`：不可拆原子自身宽度超过上限；
  - `too-many-lines`：即使任意间隙都允许断行也需要四行以上；
  - `punctuation`：三行内容纳得下，但行首/行尾禁断标点规则下无合法断点。

排版完全在浏览器内完成（复用与 Node 相同的 `src/wrap.js`），调整宽度或开关即时重算、无需重新请求后端。
「下载单语 output.srt」「复制 SRT」以及 SRT 文本页取排版后的文本；关闭开关（或宽度输入非法）时恢复原始排版。

「**排版逐条对照**」标签页逐条并排展示：输出编号与时间区间、**原文**、**排版结果**（按行显示并给出
每行宽度/剩余宽度），无解条目显示警告标记与具体原因。

## 双语字幕配对（结果页）

生成主字幕重排结果后，在结果页「**双语字幕配对**」工具条粘贴与主字幕**在同一源时间轴上的译文 SRT**
（时间轴沿用源字幕时间，正文为译文），点击「**配对译文**」：

- 译文先**沿用本次的剪辑段与倍速**调用同一 `/api/remap` 重排，再与主字幕结果配对（配对在浏览器内完成，复用 `src/pair.js`）。
- 译文 SRT 格式错误时，**按原有条目**（第几块/第几行及原因）显示在双语工具条内，
  **不会清除主字幕结果**，单语下载等功能照常可用；修正后重新配对即可。
- 重新生成主字幕结果后，旧配对自动失效（译文文本保留），需重新点击「配对译文」。

配对规则（只在**同一剪辑段**内进行）：

1. 段内主字幕与译文各自按**输出起点升序、同起点按原字幕顺序**排列；
2. 在两个有序序列之间做**保持顺序的一对一配对**，候选须在输出时间轴上有**正时长交集**
   （半开区间，端点相接不算）；
3. 择优：先最大化**配对交集毫秒总和**；总和相同取**配对数最多**；
   再相同则取「(主字幕输出编号, 译文原序)」配对序列中**字典序最小**者。

「**双语配对**」标签页列出：全部配对（主编号/时间/段/主文、译文源序与输出编号、交集毫秒）、
**未配对译文**、**未配对主字幕**，以及双语 SRT 预览。

- 「**下载双语 output-bilingual.srt**」「复制双语 SRT」：以**主字幕的时间与编号**为准，
  每条主字幕占一个条目，正文**先主文后译文**（中间换行）；
  **未配对主字幕保留单语**，**未配对译文不进入文件**。
- 启用自动换行时双语文件的**主文取排版后文本**；译文不重新排版。
- 单语「下载单语 output.srt」「复制 SRT」与自动换行功能不受影响，继续可用。

## 源字幕勘误回写（结果页）

在结果页「**源字幕勘误**」标签页（或「输出字幕列表」每行的「勘误」按钮）对输出条目的
**未排版正文**提交修订，修订按**源字幕**归并回写：

- **按源字幕归并**：同一源字幕因跨切点拆分或重复剪辑产生的多条输出**共享同一份源文修订**；
  对其中任意一条输出提交即作用于对应源字幕。
- **冲突裁决**：同一源字幕被提交了不同正文时，各版本全部列为候选，**必须显式选定一版**才生效
  （不会以最后一次编辑覆盖）；存在未裁决冲突时**禁止导出与预览**。
- **校验**：修订正文不能为空，也不得包含空白行（仅含空白字符的行）；非法提交当场拒绝、不计入状态。
- **未修订保持原文**：未修订的源字幕（包括未进入输出的）保持原文，源时间与条目顺序完全不变。
- **撤销**：每条修订可单独撤销，恢复原文。

「**下载勘误后源 output-source-corrected.srt**」「复制勘误后源 SRT」导出修订后的源 SRT；
页面同时按**当前剪辑段**对勘误后的源字幕重新重排并给出预览（复用同一 `/api/remap`，不新增后端接口），
预览中同一源字幕的多条输出文本一致。

重新点击「生成重排字幕」后主结果更新，**勘误状态随之清空**；自动换行与双语配对功能互不影响，继续可用。

## 成片口播稿核对（结果页）

生成主字幕重排结果后，在结果页「**成片口播稿核对**」工具条粘贴按**成片播放顺序**整理的
口播**纯文本**（无需编号与时间），点击「**核对口播稿**」：稿件与**当前未排版的输出字幕**
对齐（自动换行/排版设置不影响核对）。

词元化、保序一对一匹配与差异片段提取全部在**本地 Web Worker**（后台线程）中完成，
算法与 Node 测试共用同一份 `src/voicecheck.js`，核对结果与迁移前完全一致，不请求后端、
不新增接口。提交时**固定当前稿件与当前未排版字幕的快照**（仅取核对所需字段）发给 Worker，
之后的界面变化（如重新排版）不影响本次核对；计算期间页面保持响应，
**可继续编辑稿件、切换页签或取消**。

- **计算状态与取消**：工具条显示「正在后台核对」状态并出现「**取消核对**」按钮；
  每页最多运行一个核对任务，取消会**终止（terminate）Worker**并**立即可重新提交**；
  完成、取消或异常后 Worker 即被释放。
- **失效规则**：再次提交、编辑稿件、开始重新生成主结果或清空页面时，
  **旧任务与旧报告立即失效**；旧任务迟到的成功或错误消息一律被忽略，不会改变当前状态。
- **失败提示**：Worker 加载或运行失败时在工具条内给出明确提示并恢复可操作状态，
  **不会退回主线程计算**；修正环境后重新点击「核对口播稿」即可。

字幕侧先把**全部输出正文按输出顺序直接串接成一段连续文本**（条目之间不加分隔符），再按下列
规则切分词元——因此一个完整英文单词被字幕条目边界拆开（前一条以 ASCII 字母数字结尾、
后一条以 ASCII 字母数字开头，如 `…wo` + `rld…`）时，串接后仍聚成同一个词元参与匹配，
不会被误报为差异。每个词元以其**起点所在条目**的输出编号与时间定位。

词元化（两侧规则相同）：

- **连续 ASCII 字母数字 `[A-Za-z0-9]+` 算一个词元**（匹配时大小写不敏感）；
- **其他 Unicode 字母或数字按字素簇逐个计**（以 `Intl.Segmenter` 字素簇切分，
  含全角字母数字、组合字素簇等；仅 ASCII 做大小写折叠）；
- **忽略空白、标点和符号**。

匹配规则为两侧词元序列之间的**保序一对一匹配**：先**最大化匹配词元数**（最长公共子序列）；
匹配数相同时，取**匹配对序列**「(稿件位置, 字幕位置)」**字典序最小**的方案——
即固定稿件位置时优先在最靠前的可达成最优的字幕位置配对。

报告列出两类差异：

- **稿件未匹配片段**：稿件中连续未匹配词元组成的最大游程（游程内部的标点空白随原文保留），
  只用**前/后相邻的已匹配字幕**定位（显示输出编号与时间，可点击跳转；开头/结尾片段其中一侧为「—」）；
- **字幕多出片段**：字幕侧连续未匹配词元的最大游程，跨输出条目边界时**按条目拆开**，
  每条标注**输出编号与输出时间**（均可点击跳转到「输出字幕列表」）；跨条目整词归属其
  **起点所在条目**，片段原文完整显示整词（含其后一条目内的部分）。

工具条显示稿件/字幕词元数、匹配词元数与稿件覆盖率，以及两类片段的数量。

- **空输入**（空字符串或只含空白/标点/符号）、**任一侧词元数超过 1500** 时在工具条内给出明确提示，
  **不生成报告**（同时清掉旧报告视图）；
- **重新生成主结果、编辑稿件或清空页面后旧报告自动失效**（稿件文本保留，需重新点击「核对口播稿」）；
- 现有下载（单语/双语/勘误后源）、双语配对、源字幕勘误与自动换行功能**互不影响，照常可用**。

## 字幕时间避让（结果页）

生成主字幕重排结果后，在结果页「**字幕时间避让**」工具条设置两个参数（均为整数毫秒，
修改即自动重算，全部计算在浏览器内由 `src/avoid.js` 完成，不新增后端接口）：

- **最小间隔**（0～500）：相邻输出字幕新起点与前一条新终点之间至少相隔的毫秒数
  （0 表示允许首尾相接，只需不重叠）；
- **最大平移量**（0～1000）：每条字幕允许平移的绝对值上限（前移为负、后移为正）。

避让以**当前未排版输出字幕**为输入（自动换行/排版设置不影响计算），**最多处理 200 条**，
超过时在工具条内提示且不计算。每条字幕只能按**整数毫秒整体平移**（起点、终点一起移动），
并满足：

- 平移量绝对值不超过最大平移量；
- **正文、时长、编号、来源对应关系与原有顺序完全保持**；
- 新起止不越出所属剪辑段**取整后**的输出区间（见「剪辑段时间轴」的输出起止）；
- 相邻输出字幕（**含跨剪辑段**）至少相隔设定的最小间隔。

**择优**：在全部可行排程中，先**最小化平移绝对值总和**；同分取**新起点序列字典序最小**者
（同等代价下让靠前的字幕尽量早开始，即优先前移而非后移）。
算法为后缀 DP（每条字幕候选起点至多 2001 个，配合后缀最小值优化）加正向贪心重建，
200 条规模瞬时完成。

「**时间避让对照**」标签页逐条列出：输出编号、所属剪辑段、**原时间区间**、**新时间区间**、
**位移（ms，前移负/后移正/未动 0）**、时长与未排版正文；工具条显示总平移、最大单条位移与
平移条数。「**下载避让版 output-avoid.srt**」「复制避让版 SRT」以**新时间与原编号顺序**导出
（正文取未排版原文）。

- **无解时**指出**最短不可行前缀的末条输出编号**（前 k−1 条可排、前 k 条排不下），
  并**禁用避让版下载**；可尝试增大最大平移量或减小最小间隔；
- **重新生成主结果时清空旧排程**（避让参数保留，自动按新结果重算）；
- 现有下载（单语/双语/勘误后源/避让版）、双语配对、源字幕勘误、口播稿核对、
  成片同步校准与自动换行功能**互不影响，照常可用**（避让不改动主结果时间轴，仅导出独立副本）。

## 阅读时窗审计（结果页）

生成主字幕重排结果后，在结果页「**阅读时窗审计**」工具条设置**每秒可读单位数
（1～40 的整数）**即自动审计（全部计算在浏览器内由 `src/readaudit.js` 完成，
不新增后端接口、不请求后端）。审计以**当前未排版输出字幕**为输入
（自动换行/排版设置不影响审计），**不改动任何字幕**，也不影响任何下载。

- **阅读量计量**：按**字素簇**计（以 `Intl.Segmenter` 字素簇切分，与自动换行一致）：
  **ASCII 字素簇计 1，其他字素簇（汉字、全角标点、emoji 及 ZWJ 组合）计 2，
  空白不计**。
- **时窗约束**：每条字幕只能在其**半开显示区间** `[start, end)` 内阅读
  （**端点相接不算重叠**，如 `[0,1000)` 与 `[1000,2000)` 在 1000 处不共享容量）；
  阅读是**可暂停、继续的单人任务**，同一时刻总速度不超过设定值（不并行）。
- **分配规则**：**最早截止时间优先（EDF）**——任意时刻把全部阅读速度分配给
  “当前可见且未读完”中截止时间最早的一条；截止时间相同时按**输出编号**升序。
  被更早截止的字幕抢占时自动暂停（已读量保留），之后可继续。
- **整数千分之一单位、不逐毫秒取整**：阅读量内部以**千分之一阅读单位（毫单位）
  的整数**记录（需求 = 计权簇数 ×1000）。读完时刻可以是分数毫秒（例如速度 9、
  需求 2 单位需 2000/9 ms），时间点内部用 **BigInt 有理数（分子/分母）**表示，
  区间容量 `速度 × 时长` 分数对消后仍是整数毫单位，**全程无浮点误差、不逐毫秒
  取整**。到截止仍未读完的余量记为**欠量**并随该条移除。
- **最早失约时刻**：存在欠量时，取欠量字幕中**最早的显示截止点**（半开区间终点；
  同一时刻多条并列失约时一并标出），工具条与标签页顶部高亮显示该时刻
  （`HH:MM:SS,mmm` 与整数毫秒）。
- **边界情形**：显示区间**重叠、端点相接、重复剪辑**（同文同窗口的多条输出各自
  独立计量与调度）以及**不足一秒的字幕**（个位数毫秒窗口）都正确处理；
  纯空白/空文本字幕为**零需求**，立即读完、不占容量。

「**阅读时窗审计**」标签页逐条列出：输出编号、半开显示区间（含整数毫秒）、
时长、**需求量、已读量、欠量**（均为三位小数的阅读单位，即整数毫单位的精确展示）、
状态（已读完/欠量/零需求；最早失约条目行内高亮）与未排版正文；工具条汇总总需求、
已读量与覆盖率、欠量条数与欠量总量、最早失约时刻，以及满速阅读/空闲毫秒数。

- **失效规则**：**调整阅读速度即时重算**；**重新生成主结果后旧结论清除**
  （按新结果与当前速度自动重算；速度非法时不审计并标红输入框）。
- 审计为只读分析：现有下载（单语/双语/勘误后源/避让版/校准版/标注版）、
  双语配对、源字幕勘误、口播稿核对、时间避让、同步校准、方案对照、说话人标注
  与自动换行功能**互不影响，照常可用**。

## 成片同步校准（结果页）

生成主字幕重排结果后，在结果页「**成片同步校准**」工具条逐行输入 **2～10 个同步锚点**
（每行 `旧毫秒 新毫秒`；字段间用**空白或逗号**分隔，`#` 之后为注释，空行忽略），
点击「**应用校准**」：以当前**未排版输出字幕**的毫秒时间为**旧轴**，把每条输出字幕的
起止映射到成片（新）时间轴（全部计算在浏览器内由 `src/sync.js` 完成，不新增后端接口）。

- **锚点校验**：两列均须为**非负整数**且**各自严格递增**；锚点总数须为 2～10 个。
  字段数、非整数、负数与不严格递增等错误**指出具体行号**（不严格递增时同时给出前一锚点
  所在行号），只显示在校准工具条内，**不覆盖主结果**；单语/双语/勘误后源/避让版下载等
  照常可用，修正后重新点击「应用校准」即可。
- **映射规则**：相邻锚点之间按**线性比例**映射
  `f(t) = 新_i + (t − 旧_i)·(新_{i+1} − 新_i) / (旧_{i+1} − 旧_i)`；
  **首锚点之前**沿用首锚点的**固定偏移**（`f(t) = t + (新_0 − 旧_0)`），
  **末锚点之后**沿用末锚点的**固定偏移**。锚点处两侧公式一致（`f(旧_i) = 新_i`），
  整条映射连续且单调不减。
- **精度**：映射全程以**整数分子/分母**（有理数，BigInt）保留精确值，不做任何浮点近似；
  只在最后把每条字幕的起止边界**分别四舍五入**为整数毫秒（0.5 向上，与主重排的取整规则一致）。
- **内容不变**：正文取**未排版原文**，编号、顺序与来源对应关系完全不变（导出时仍按
  输出顺序从 1 编号，与原输出编号一致）。
- **禁用导出**：若校准后出现**负时刻**（精确值 < 0）或**取整后零长**（四舍五入后
  终点不晚于起点）的字幕，逐条**指出输出编号**并**禁止校准版导出**（下载/复制按钮禁用）；
  对照页仍逐条展示并高亮问题行，**主结果与其他功能不受影响**；调整锚点后重新应用即可。
- **失效规则**：**修改锚点或重新生成主结果后旧校准立即失效**（锚点文本保留，
  需重新点击「应用校准」）。

「**同步校准对照**」标签页逐条列出：输出编号、**原时间区间**、**校准时间区间**、
**起点偏移/终点偏移（ms）**、**时长（原 → 新）**与未排版正文；问题行高亮并标注
「负时刻」或「取整后零长」。「**下载校准版 output-synced.srt**」「复制校准版 SRT」
以**校准时间与原编号顺序**导出；不可导出时下载与复制保持禁用。

## 剪辑方案对照（结果页）

生成主字幕重排结果后，在结果页「**剪辑方案对照**」工具条输入**方案 B 的剪辑段**
（格式同主剪辑段：每行 `源起ms 源止ms 倍速`），点击「**对照方案**」：
以已生成结果的**源 SRT 与剪辑段为方案 A**，逐条源字幕对照两套剪辑方案
（全部计算在浏览器内由 `src/plancompare.js` 完成，不新增后端接口）。

- **方案 B 校验**：沿用与主剪辑段完全相同的解析与校验规则（`src/segments.js`，
  浏览器内复用同一模块）；格式错误**只显示在对照工具条内**（定位到方案 B 第几行），
  **不覆盖主结果**，单语/双语/勘误后源下载等照常可用；修正后重新点击「对照方案」即可。
- **对照算法**：对每条源字幕，把两套剪辑段与其**半开源区间** `[start, end)` 的交集端点
  合并排序，切成源时间轴上的**连续小区间**；逐区间统计两方案的：
  - **覆盖次数**：该小区间被多少条剪辑段覆盖（**重叠、重复源段各自计入**，未命中计 0）；
  - **精确播放时长**：按各覆盖段倍速折算（源时长 ÷ 倍速）后求和，
    以**半毫秒**为整数单位累计，**不先取整**（0.5 / 1 / 2 三档倍速下全程无浮点误差）。
- **只列出差异区间**：仅当某小区间的覆盖次数或精确播放时长两方案不同时才列出，
  逐区间显示**两侧数值与差值**（覆盖差、时长差 A−B）。
- **每条源字幕汇总**：列出每条源字幕在两方案下的精确播放时长与差值 A−B
  （未命中、重叠、重复源段均计入；差异相互抵消时净差可为 0，差异区间仍列出），
  差异行高亮并可点击跳转到该源字幕的差异区间明细；工具条同时给出两方案的总播放时长与总差值。
- **无差异时明确提示**：两方案在全部源字幕上覆盖与播放时长完全一致时，
  工具条与标签页均明确提示「无差异」。
- **失效规则**：修改源 SRT、主剪辑段（方案 A）、方案 B，或重新生成主结果后，
  **旧对照立即失效**（方案 B 文本保留，需重新点击「对照方案」）。

「**方案对照**」标签页展示：每条源字幕播放时长汇总表（源序号/源时间区间/文本/
方案 A 时长/方案 B 时长/时长差/差异区间数）与差异区间明细
（源区间、区间长、两侧覆盖次数与差值、两侧精确播放时长与差值）。

## 说话人标注（结果页）

生成主字幕重排结果后，在结果页「**说话人标注**」工具条逐行输入**源时间轴**上的说话人时段
（每行 `起始毫秒 结束毫秒 说话人ID`；字段间用**空白或逗号**分隔，`#` 之后为注释，空行忽略），
点击「**应用标注**」：标注时段沿用本次剪辑段、倍速与边界取整规则映射到成片，
并为每条**未排版输出字幕**判定说话人归属（全部计算在浏览器内由 `src/speaker.js` 完成，不新增后端接口）。

- **标注校验**：起始/结束时间须为**非负整数**且**起点小于终点**；说话人 ID 限
  **1～20 位 ASCII 字母、数字、下划线或连字符**；**不同说话人的时段可重叠**。
  字段数、非整数、负数、倒置区间与非法 ID 等错误**指出具体行号**，只显示在标注工具条内，
  **不覆盖主结果**；单语/双语/勘误后源/避让版/校准版下载等照常可用，修正后重新点击「应用标注」即可。
- **映射规则**：每条标注时段与主重排完全一致——与各剪辑段求**半开交集**、按倍速换算
  （内部以半毫秒精确单位累计）、边界最后分别**四舍五入**为整数毫秒（0.5 向上）；
  四舍五入后零长的片段舍弃。同一条标注被多个剪辑段（含重复段）覆盖时各自独立映射。
- **归属判定**：对每条未排版输出字幕，仅统计**同一剪辑段**内与各说话人时段的
  **正时长交集**（半开区间，端点相接不算）；**同一人的重叠时段先取并集**，不重复计时。
  交集时长**最长**者为该字幕的说话人；**无交集者保持无标签**。
- **并列裁决**：最长交集并列时，该字幕的全部并列说话人列为候选，需**逐条显式裁决**
  （可改选）；**存在未裁决并列时禁用标注版导出**（下载/复制按钮保持禁用，
  主结果与其他下载不受影响）。
- **失效规则**：**修改标注或重新生成主结果后，旧归属、裁决及标注版导出立即失效**
  （标注文本保留，需重新点击「应用标注」）。

「**说话人标注**」标签页逐条对照：输出编号、输出时间区间、所属剪辑段、
**各说话人的交集时长（ms）**、**归属**（说话人 ID / 并列候选裁决按钮 / 无标签）与未排版正文；
未裁决的并列行高亮。「**下载标注版 output-speakers.srt**」「复制标注版 SRT」以
**原时间与原编号顺序**导出：**已归属字幕的正文前加「[ID] 」**，时间、编号及原正文其余部分不变
（正文取未排版原文，多行正文仅在首部加前缀）；无标签字幕正文保持原样。

## 映射规则

- 字幕区间 `[start, end)` 与剪辑段区间 `[sourceStart, sourceEnd)` 均为**半开区间**，
  交集 `lo = max(start, sourceStart)`、`hi = min(end, sourceEnd)`，仅当 `lo < hi` 时命中；
  端点恰好相接（`lo == hi`）**不**产生交集，未命中任何段的字幕丢弃。
- 命中部分按倍速映射到该段在拼接时间轴上的位置：
  `输出偏移 = (源偏移) / 倍速`。即 2× 压缩一半、0.5× 拉长一倍。
- **跨切点拆分**：一条字幕与多个段（或被同一段在多次重复中使用）相交时拆成多条输出。
- **重复段**：同一源段出现多次时，每次都独立生成输出字幕。
- **精确累计**：内部以半毫秒（0.5ms）为整数单位累计，0.5 / 1 / 2 三档倍速全程无浮点误差；
  输出边界最后**四舍五入到毫秒**（0.5 向上）。
- **零长片段舍弃**：交集存在但映射并四舍五入后起止相同（不足 1ms）的片段不进入输出，
  页面会单独列出其源字幕、所属剪辑段与精确区间；四舍五入后的拼接总时长以实际累计为准。
- **多行文本**原样保留（不做合并或裁剪）。
- 输出按**起点升序**排序；起点相同时，先按**剪辑段播放顺序**、再按**原字幕顺序**排序，然后从 1 重新编号。

## 页面内容

- **剪辑方案对照工具条**：输入方案 B 剪辑段；对照/清空、方案 B 错误条目提示（不影响主结果）、差异与总时长统计。
- **说话人标注工具条**：逐行输入源时间轴的「起始毫秒 结束毫秒 说话人ID」；应用/清空、标注错误行号提示（不影响主结果）、归属与并列裁决统计。
- **源 → 输出 对应关系**：每条源字幕的状态（已采用 / 未命中丢弃 / 零长舍弃）与生成的输出编号（可点击跳转）。
- **排版逐条对照**：每条输出字幕的原文与自动换行结果（行宽、剩余宽度、无解原因）。
- **时间避让对照**：每条输出字幕的原时间区间、新时间区间、位移（前移/后移/未动）、时长与未排版正文；

- **方案对照**：每条源字幕播放时长汇总（两方案精确时长与差值 A−B，差异行高亮可跳转）、
  差异区间明细（源区间、两侧覆盖次数与精确播放时长及差值）、无差异时的明确提示。
- **说话人标注**：每条输出字幕的各说话人交集时长与归属（并列候选逐条裁决、未裁决行高亮并禁用标注版导出）、
  无标签条目标识；可下载/复制标注版 SRT（已归属字幕正文前加「[ID] 」，时间与编号不变）。
- **源字幕勘误**：输出条目勘误（按源字幕归并、同源共享一份修订）、冲突候选裁决、已提交修订列表、
  勘误后源 SRT 文本与按当前剪辑段重新重排的预览（同源输出文本一致）。
- **输出字幕列表**：新编号、新时间区间、时长、来源（源序号 / 剪辑段 / 输入行号）、倍速、源内交集、文本（启用排版时显示排版后文本）。
- **剪辑段时间轴**：每段的源区间、倍速、输出起止与精确段时长。
- **SRT 文本**：最终序列化结果（启用排版时为排版后文本），可下载（单语）或复制。

## 错误提示

输入有误会返回 HTTP 400 并在页面上分组列出，**定位到具体条目**：

- SRT：指出第几块（及文件行号）与原因——序号非数字、时间轴格式错误、结束不晚于开始、缺少文本等。
- 剪辑段：指出第几行与原因——字段数不对、起止时间非整数/为负、结束不晚于开始、倍速不在允许范围等。

双语配对时译文 SRT 的错误同样返回 400，但只显示在结果页双语工具条内（第几块/第几行），
主字幕结果与单语下载不受影响。

剪辑方案对照时方案 B 的剪辑段错误在浏览器内按同一解析规则校验，只显示在对照工具条内
（方案 B 第几行），主结果与各项下载不受影响。

成片同步校准时同步锚点错误在浏览器内校验（字段数/非整数/负数/两列不严格递增/数量 2～10），
只显示在校准工具条内并指出锚点行号，主结果与各项下载不受影响；
校准后出现负时刻或取整后零长字幕时指出输出编号并禁止校准版导出。

说话人标注的输入错误在浏览器内校验（字段数/非整数/负数/起点不早于终点/ID 非法或超长），
只显示在标注工具条内并指出标注行号，主结果与各项下载不受影响；
最长交集并列的字幕需逐条裁决，未裁决前禁用标注版导出。

## HTTP 接口

`POST /api/remap`，请求体：

```json
{ "srt": "1\n00:00:00,000 --> 00:00:01,000\n你好\n", "segments": "0 1000 1\n" }
```

成功返回 `200`：`srt`（序列化后的文本）、`mappings`、`sourceRows`、`timeline`、`dropped`、`stats`。
输入非法返回 `400`：`{ "errors": [{ "type": "srt|segment", "block|line": 3, "message": "..." }] }`。

双语功能复用同一接口：以译文 SRT 与本次剪辑段文本再次调用 `/api/remap`，
配对计算在浏览器内由 `src/pair.js` 完成，不新增后端接口。

源字幕勘误同样复用该接口：以勘误后的源 SRT 与本次剪辑段再次调用 `/api/remap` 生成重排预览，
归并、冲突裁决与导出校验均在浏览器内由 `src/correct.js` 完成，不新增后端接口。

成片口播稿核对完全在浏览器内完成：词元化、保序一对一匹配（LCS DP）与差异片段提取由
本地 Web Worker（`public/voicecheck-worker.js`，内部 `importScripts` 复用 `src/voicecheck.js`）
在后台线程执行；任务生命周期（单任务、取消、失效、迟到消息忽略、Worker 释放）由
`src/vcrunner.js` 管理，不请求后端、不新增接口。

字幕时间避让同样完全在浏览器内完成：可行域构造、最短不可行前缀判定、最小总平移 DP 与
字典序最小重建均由 `src/avoid.js` 完成，不请求后端、不新增接口。

阅读时窗审计也完全在浏览器内完成：字素簇阅读量计量（ASCII 簇 1/其他簇 2/空白不计）、
半开时窗约束、最早截止时间优先（同截止按输出编号）的可暂停/继续单读者 EDF 事件扫描、
BigInt 有理数时间与整数千分之一单位（不逐毫秒取整）、欠量与最早失约时刻统计均由
`src/readaudit.js` 完成，不请求后端、不新增接口、不改动字幕。

成片同步校准也完全在浏览器内完成：锚点解析与逐行校验（两列非负整数且严格递增）、
整数分子/分母（BigInt 有理数）的区间内线性比例映射与首末固定偏移、边界分别四舍五入、
负时刻/取整后零长判定均由 `src/sync.js` 完成，不请求后端、不新增接口。

剪辑方案对照也完全在浏览器内完成：方案 B 复用 `src/segments.js` 解析校验，
区间切分、覆盖次数与精确播放时长统计由 `src/plancompare.js` 完成，不请求后端、不新增接口。

说话人标注也完全在浏览器内完成：标注时段解析与逐行校验（非负整数、起点小于终点、
ID 限 1～20 位 ASCII 字母数字下划线连字符）、沿用剪辑段/倍速/取整规则的成片映射、
同段正时长交集（同人先并集）与最长归属/并列判定、标注版条目生成均由 `src/speaker.js`
完成，不请求后端、不新增接口。

健康检查：`GET /healthz`。

│   ├── vcrunner.js        # 口播稿核对 Worker 生命周期：单任务、快照提交、取消/失效、迟到消息忽略、Worker 释放（双端通用）
